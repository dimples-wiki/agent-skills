# 选配模式（默认不用）

两种模式都**只在用户明确提出后**触发；默认生成不含它们，以保住输出速度。
本文件是 SKILL.md「选配模式」一节的展开，仅在触发时读。

## 寓言故事模式

触发词：页面交付后用户说「补充寓言故事」「加个寓言帮我记」「要个记故事的」/ fable。

执行：

1. 读 `assets/fable.md`（寓言写作契约 —— Step 1「零 skill 文件读取」的唯一例外，
   仅限本阶段），并复读已生成页面的正文 —— 寓言必须与页面讲的真实机制**同构**，
   转折映射因果，不为故事扭曲机制。
2. 按契约写 ≤1000 字寓言，用 fable.md 第五节的 HTML 骨架插入页面：
   位置在自测块（`[data-quiz]`）**之后**、数字账本（`[data-ledger]`）**之前**，
   作为全页最后一个 section；复用 tokens 类，除骨架自带的样式块外不写新 CSS；
   自测块与账本保留不动。
3. 两问之后写答案藏进「查看答案」按钮（fable.md 骨架的 `[FABLE-TOGGLE]`）——
   答案区是全寓言唯一点破处（概念名 + 道具→机制映射）。
4. 寓言若引入了新的 N% / N 倍 数字，同步写进账本（门 13 扫全页正文）。
5. 重跑 `aha check`（13/13），回执沿用 SKILL.md「交付回执」格式并附寓言标题（不剧透）。

寓言**不进**第 3 层直觉层、不替代类比框 —— 页面原有的类比边界契约照旧；
寓言是终章的记忆钩子，两套类比系统并存但互不指涉。

## vgpu 着色器展示层

仅当**两个条件同时满足**：① 概念本质是连续场 / 波 / 流 / 梯度 / 海量粒子
（波干涉、损失面、注意力场）；② 用户明确要求更炫 / 实时演示。

- 核心解释**永不依赖**此层 —— 四种降级路径（无 WebGPU / `prefers-reduced-motion` /
  CDN 不可达 / 加载失败）都落回静态示意，静默无报错。
- 用 `assets/snippets/vgpu-field.html` 作起点；改 WGSL 前先 `npx vgpu check` 校验。
- 库通过运行时动态 `import("https://esm.sh/vgpu")` 懒加载（不是 `<script src>`，
  门 8 不触发）；着色器 tint 从 CSS token 读取后传 uniform，WGSL 里不硬编码颜色。
  其余要求见 snippet 文件头注释；13 门照常全过。
